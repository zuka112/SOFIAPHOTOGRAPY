# sofiaphoto.com

ფოტო გალერეა სამი განყოფილებით: დამუშავებული, ორიგინალი, შავ-თეთრი.

## პირველი გაშვება (ერთხელ)
1. GitHub-ზე შექმენით Public რეპოზიტორია `sofiaphoto` და ატვირთეთ ყველა ფაილი (მათ შორის `.github` საქაღალდე).
2. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions** ჩანართში დაელოდეთ მწვანე ნიშანს ✓ (1–2 წუთი) — საიტი მზადაა.

## ფოტოების ატვირთვა
გახსენით საჭირო საქაღალდე → **Add file → Upload files**:

| საქაღალდე | განყოფილება |
|---|---|
| `photos/edited` | დამუშავებული |
| `photos/original` | ორიგინალი |
| `photos/bw` | შავ-თეთრი |

ატვირთვის შემდეგ GitHub ავტომატურად ქმნის პატარა ასლებს გალერეისთვის და აქვეყნებს საიტს (1–2 წუთი).
ორიგინალი ფაილი არ იცვლება — ფოტოზე დაჭერისას სრული ხარისხით იხსნება.
